# Fabrication files

`AT-DX1_Gerbers_RP2354A_v1.0_2026-09-14.zip` is the unmodified Gerber archive supplied for the 2026-09-14 V1.0 hardware snapshot.

Archive contents include:

- Top copper
- Bottom copper
- Inner layer 1
- Inner layer 2
- Top and bottom solder mask
- Top and bottom silkscreen
- Top and bottom paste mask
- PTH, NPTH and via drill data
- Board outline
- Document layer

Upload the ZIP itself to the PCB manufacturer's Gerber importer rather than recompressing individual layers unless the manufacturer specifically requests otherwise.
