# Contributing to AT-DX1

AT-DX1 is an experimental amateur-radio hardware/software project. Contributions, test results and reproducible issue reports are welcome.

For hardware reports, please include the PCB revision, component substitutions, band, supply voltage, test load and the measurement equipment used where relevant.

For firmware reports, include the RP2350 Arduino core version, relevant library versions, host operating system/application and the exact firmware file/commit being tested.

Do not submit third-party code or design files unless their licence permits redistribution and the original copyright/licence notice is included.

RF changes should be tested into a suitable dummy load before they are recommended for on-air use.
